Deep learning is a subset of machine learning. Here, “traditional ML” means approaches such as Naive Bayes and logistic regression.
01 / TEXT CLASSIFICATION
@

Email spam detection

Classify a message as spam or legitimate. A traditional ML baseline can turn email text into numerical features and learn from labeled messages.

Email text→TF-IDF features→Classifier
Candidate approach
Naive Bayes or logistic regression.
Why consider it
A practical starting point for sparse text features, with relatively modest training requirements.
What I would evaluate
Precision and recall, especially legitimate emails incorrectly flagged as spam.
02 / IMAGE CLASSIFICATION
▧

Medical image analysis

Explore how a convolutional neural network could learn visual features from labeled images for a defined classification task.

Image→Learned features→Prediction
Candidate approach
A CNN, potentially adapted from a pretrained model.
Why consider it
Convolutional layers learn spatial patterns instead of relying only on manually selected image features.
What I would evaluate
Performance on held-out patients, error patterns, and whether the data represents the intended population.
